Trilhas de prática

Como funciona

  1. Escolha uma trilha e leia o artefato (trecho de registro, log, script ou XML).
  2. Descubra a resposta — pode ser um caminho, um Event ID, uma saída de script ou uma flag CTF{...} escondida.
  3. Digite no campo e clique em Verificar. Dicas custam 50 pts — e a explicação comentada fica sempre disponível.
  4. Use o Terminal simulado para treinar comandos — existe uma flag escondida lá dentro.
